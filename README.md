# Portfolio OS

A desktop-inspired portfolio website developed by Jeevan Kumar S.

---

## About

This repository contains the source code for my personal portfolio website.

The portfolio showcases my projects, research papers, certifications, technical skills, and achievements, reflecting my journey as a developer, researcher, and technology enthusiast.

---

## Features

- Desktop-style user interface
- Draggable and resizable windows
- Project showcase with detailed views
- Research paper management
- Certificate gallery
- Skills and technology overview
- CSV-based content management
- Responsive design

---

## Technologies

- HTML5
- CSS3
- JavaScript
- CSV-based data management
